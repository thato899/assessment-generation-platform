# API documentation

The current contract is exposed by FastAPI at `/openapi.json` and `/docs`. The stable namespace is `/api/v1/`; breaking changes require a new version.

The v1 generation contract and its current supported capability are documented in [v1-assessment-generation.md](v1-assessment-generation.md). Application orchestration is documented in [assessment-generation.md](../application/assessment-generation.md).
